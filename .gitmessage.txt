

# [#이슈번호] type(scope): 한 줄 요약
# 예: [#3] feat: 발주 등록 API 구현
#     [#5] fix(order): 중복 발주 방지 로직 수정

# -------------------------------------------------
# Commit type guide (삭제해도 됨)
# feat     : 기능 추가
# fix      : 버그 수정
# refactor : 리팩터링
# style    : 코드 스타일 (포맷팅, 세미콜론 등 동작 변경 없음)
# perf     : 성능 개선
# docs     : 문서
# test     : 테스트
# chore    : 기타 작업
